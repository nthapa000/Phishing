# My First Browser Extension

A simple browser extension to learn extension development.

## Files Structure
- `manifest.json` - Extension configuration file
- `popup.html` - The popup that appears when clicking the extension icon
- `popup.js` - JavaScript for the popup functionality
- `images/` - Directory containing extension icons

## How to Load the Extension

1. Open Chrome/Edge browser
2. Go to `chrome://extensions/` or `edge://extensions/`
3. Enable "Developer mode" (toggle in the top right)
4. Click "Load unpacked"
5. Select the directory containing these files

## Features
- Simple popup interface
- Button that shows an alert when clicked

## Note
You'll need to add icon files in the `images/` directory:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)
